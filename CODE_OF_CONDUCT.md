# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

## TL;DR

- Be respectful, inclusive, and constructive.
- Disagreements are welcome — personal attacks are not.
- Assume good faith. Ask questions before assuming malice.
- Credit others' work. Cite sources.
- If you see behavior that violates the Covenant, report it (see below).

## Scope

This Code applies to all project spaces — issues, pull requests, discussions,
commit messages, code review, and any communication that happens "as a
contributor to Biz Checks." It also applies to public spaces when an
individual is officially representing the project.

## Reporting

To report unacceptable behavior, email **jwillz7667@gmail.com** with:

- Where the incident happened (link to the issue / PR / thread).
- What was said or done.
- Who was involved.
- Anything else you think is relevant (screenshots, prior context).

Reports are handled confidentially. We will acknowledge within 2 business days
and respond with a disposition within 7. Reporters will not face retaliation
for filing a good-faith report.

## Enforcement

The full enforcement guidelines are described in section 4 of the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
Consequences range from a private written warning up to a permanent ban from
all project spaces, depending on severity and pattern.
